# Clude_test

四舵轮 AMR + 七轴机械臂的浏览器 3D 仿真（单文件 HTML + Three.js r128）。

## 运行

用 Chrome / Edge 直接打开 `四舵轮AMR + 七轴机械臂（带帧率显示）.html` 即可。`three.min.js` 必须和 HTML 放在同一文件夹（已本地引用，不依赖外网）。

## 功能

- **底盘**：四舵轮全向运动；底盘 A（前刚性 + 后跷跷板）/ 底盘 B（四轮独立悬挂，可逐轮锁止）。登车桥抬升时悬挂行程保持为 0，只有局部凸起由悬挂吸收。
- **场景**：空旷场地、20GP 标柜、20HQ 高柜（含月台、可调坡度登车桥、车尾伸缩输送线、月台输送线）。车体不能穿过箱壁、门柱、货面。
- **机械臂**：可切换——7 自由度冗余臂（J2–J4 平行；大臂 800 mm、小臂 600 mm、前臂 700 mm，经扫参优化），或 6 轴 FANUC M-20iD/35（J2 高 525 mm、大臂 780 mm、小臂 850 mm、腕→法兰 100 mm，臂展 1831 mm；无冗余）。两者都用解析逆运动学；奇异位形分析（最小奇异值 + 腕部/臂伸直/肩部三类）。
- **吸盘抓取**：5×10 分区吸嘴；自动抓取、连续卸货（先最外面一面、再从上往下）。抓取时车头与货面至少留约 76 cm。
- **装车仿真**：机械臂面板里“清空车厢 → 自动装车”。箱子从月台输送线外端送来，经车尾输送线停在机器人正后方止挡处；机械臂吸取后在车厢内由里向外、自下而上、每层由两侧向中间码垛（输送带上一律顶吸；其余层顶放；最上层顶吸的吸盘板放不进车顶空隙，所以先把箱子放到槽位前的车厢地面上中转，换成前吸再抬起水平推入）。搬运路径复用卸货规划的时间反演。
- **装卸速度**：机械臂面板里的“装卸速度”滑块（×0.5–×3，默认 ×1.5，记在浏览器里），同时调节关节速度、吸盘板/真空动作、流程停顿、输送线线速（最多 ×2）、自动挪车和送箱节拍。
- **箱子物理**：重力、落地弹跳与摩擦、堆叠、箱与箱/货垛/箱壁/车体碰撞、车顶板上的箱子随车走。
- **传感器**：4 台 Livox Mid-360 雷达（默认：车头正中离地 400 mm、左前/右前顶板边缘倒装朝下外倾 20°、车尾离地 400 mm；位姿各自可调，被车体/机械臂/箱子/集装箱遮挡；点云可按高度/雷达/距离/命中类型/反射强度着色，可开关测距噪声、调点密度）；3 台 RGB-D 相机（迈尔微视 M4 Pro，上相机可升降）。
- **界面**：各面板可拖动（位置会记住）；左上角显示帧率与各部分耗时；测距显示车头到最外侧箱子的距离。

## 操作

- 鼠标：左键旋转、右键 / Shift+左键平移、滚轮缩放。
- 键盘：W/S 前后，A/D 左右平移，Q/E 旋转。
